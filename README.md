# StitchWise AI — Browser Edition v0.1.1

A browser-only embroidery stitch inspector. No Electron, Windows app, npm install, cloud account, or external AI service required.

## Run on Windows

1. Extract this ZIP.
2. Open PowerShell inside the `StitchWise-AI` folder.
3. Run `node server.cjs`.
4. Open http://localhost:4173 in your browser.

Node.js is required for the local web server, but no packages need to be installed. Keep the PowerShell window open while using the app. Alternatively run `python -m http.server 4173` if Python is installed.

## Current functionality

- Import DST and EXP machine embroidery files locally.
- Zoom and pan a color-coded stitch path viewer.
- Screen for short stitches, long stitches, long jumps, concentrated endpoints, hoop-size limits and frequent color changes.
- Highlight stitch segments associated with selected findings.
- Get fabric-aware, rule-based repair guidance.
- Load a sample design to explore the interface.

## Limitations

- The recommendations are rule-based, not generated by a trained AI model.
- PES, JEF, VP3, XXX and other formats are not yet supported.
- The concentrated-endpoint check is a heuristic, not a physical density measurement.
- The app does not automatically edit or export repaired designs.
- Always validate recommendations with digitizing software and a sew-out.

All file processing happens locally in your browser.
